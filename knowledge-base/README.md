## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS v3, Shadcn UI
- **Backend**: Express, TypeScript, Node.js
- **Database**: PostgreSQL with Prisma ORM
- **Authentication**: JWT (JSON Web Tokens)
- **File Upload**: Multer
- **State Management**: Zustand
